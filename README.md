# Stick Impact Arena · 棍之冲击竞技场

一款使用 **Vite + TypeScript + HTML5 Canvas** 构建的 2D 火柴人格斗游戏。纯前端，无需后端，无需外部资源。

**[在线游玩](https://xiaowanwanna.github.io/stick-impact-arena/)**

---

## 游戏介绍

在赛博朋克风格的暗色竞技场中，操纵你的火柴人战士与 AI 敌人「暗影」对战。游戏注重打击感——命中时会有画面震动、冻结帧、慢动作、粒子特效和浮动伤害数字。格挡、闪避、连击、终结技，打出你的风格。

| 按键 | 动作 |
|------|------|

## 招式表

### 基础攻击

| 招式 | 按键 | 伤害 | 特点 |
|------|------|------|------|
| 轻拳 | `J` | 5 | 极快起手（0.04s），短后摇，可连续压制 |
| 重拳 | `K` | 10 | 中等起手，强击退，适合连招收尾 |
| 踢击 | `L` | 7 | 中距离 poke，出招较快 |
| 跳踢 | 空中 `L` | 8 | 空中突袭，将对手向下击落 |

### 特殊攻击

| 招式 | 按键 | 伤害 | 消耗 | 特点 |
|------|------|------|------|------|
| 闪击 | `U` | 6 | 无 | 快速突进 + 贯穿攻击，冷却 0.35s |
| 能量斩 | `I` | 16 | 40 能量 | 大范围横扫，画面震动 + 慢动作 |

## 推荐连招

### 入门连招

```
J → J → K
轻拳 ×2 接重拳收尾，最基础的压制连段。伤害约 20。
```

```
U → K
闪击突进后立刻接重拳。伤害约 16。
```

### 进阶连招

```
J → J → L → I
轻拳 ×2 → 踢击 → 能量斩。将对手推远后大范围收割。伤害约 33。
```

```
空中 L → J → J → K
跳踢起手，落地后轻拳 ×2 接重拳。伤害约 28。
```

### 高阶连招

```
U → J → K → I
闪击贯穿 → 转身轻拳 → 重拳 → 能量斩。伤害约 37。
```

```
J → J → L → O
轻拳 ×2 → 踢击确认 → 终极奥义终结。伤害约 52，直接斩杀线。
```

### 终极连招

```
空中 L → U → J → K → I → O
跳踢起手 → 闪击追击 → 轻拳 → 重拳 → 能量斩 → 终极奥义。
全中伤害约 80+，需要满能量起手。
```

## 核心机制

### 能量系统
- 基础攻击命中回复 8-14 能量
- 能量槽上限 100
- 能量斩消耗 40，终极奥义消耗 100
- 鼓励积极进攻来积攒能量

### 格挡与完美格挡
- 按住 `空格` 进入格挡状态，受到的伤害减少 85%
- 在格挡开始后的 **0.15 秒窗口内** 被击中，触发完美格挡：
  - 完全免疫本次伤害
  - 弹反对手，使其进入硬直
  - 回复 20 能量
  - 金色闪光特效

### 闪避
- 按 `U` 发动闪击，快速向前突进并攻击
- 冷却时间 0.35 秒
- 可用于穿过对手、躲避攻击或快速接近

### 连击系统
- 连续命中对手会累计连击数
- 3 连击以上屏幕中央显示连击计数
- 10 连击以上变为红色特效
- 双方脱离战斗 0.4 秒后连击重置

### 打击反馈
- **画面震动**：重攻击命中时屏幕晃动
- **冻结帧**：命中瞬间画面短暂停顿
- **慢动作**：必杀技和终结技触发慢镜头
- **粒子特效**：火花、斩击弧、冲击波、浮动伤害数字

## 本地运行

```bash
git clone https://github.com/Xiaowanwanna/stick-impact-arena.git
cd stick-impact-arena
npm install
npm run dev
```

浏览器访问 `http://localhost:5173` 即可开始游戏。

## 技术栈

- **Vite** — 构建工具
- **TypeScript** — 类型安全
- **HTML5 Canvas** — 纯手绘渲染，无外部资源
- **requestAnimationFrame** — 60fps 游戏循环
- **增量时间 (delta time)** — 帧率无关的物理更新
